# Rúbrica de Evaluación — Exposición Oral
## Unidad: El Sistema Solar | Proyecto: "Mi Planeta"

**Materia**: Ciencias Naturales | **Curso**: 6° Primaria | **Duración de la exposición**: 5-7 minutos

---

## Instrucciones para el Alumno

Cada estudiante investigará UN planeta asignado y lo presentará a la clase. La presentación debe incluir:
- Características físicas (tamaño, composición, temperatura)
- Posición en el Sistema Solar
- Al menos 3 datos curiosos o interesantes
- Por qué tu planeta es especial o único
- Un recurso visual (poster, dibujo, presentación digital, maqueta pequeña)

---

## Tabla de Rúbrica

### Categoría 1: Contenido Científico (30 puntos)

| Nivel | Puntos | Descripción |
|---|---|---|
| **Excelente** | 27-30 | Presenta información precisa y completa. Incluye todos los elementos requeridos. Aporta datos adicionales relevantes. No hay errores conceptuales. |
| **Muy bueno** | 22-26 | Información mayormente correcta y completa. Incluye la mayoría de los elementos requeridos. Algún error menor sin impacto en la comprensión. |
| **Satisfactorio** | 16-21 | Información básica correcta. Falta alguno de los elementos requeridos. Uno o dos errores conceptuales menores. |
| **En proceso** | 9-15 | Información incompleta o con errores importantes. Faltan varios elementos requeridos. |
| **Necesita mejora** | 0-8 | Información incorrecta, muy escasa o sin relación con el tema. |

---

### Categoría 2: Comunicación Oral (25 puntos)

| Nivel | Puntos | Descripción |
|---|---|---|
| **Excelente** | 23-25 | Habla con claridad, volumen adecuado y buena dicción. Mantiene contacto visual con el público. Usa vocabulario científico correctamente. El ritmo es apropiado (ni muy rápido ni muy lento). |
| **Muy bueno** | 18-22 | Habla con claridad la mayor parte del tiempo. Buen contacto visual. Usa algunos términos científicos. Ritmo generalmente adecuado. |
| **Satisfactorio** | 13-17 | Habla con suficiente claridad para ser entendido. Contacto visual ocasional. Vocabulario básico correcto. Ritmo con algunas interrupciones. |
| **En proceso** | 7-12 | Dificultades para ser escuchado o entendido. Poco contacto visual. Lee directamente de notas la mayor parte del tiempo. |
| **Necesita mejora** | 0-6 | Muy difícil de escuchar o entender. Sin contacto visual. Lee todo el texto sin pausas. |

---

### Categoría 3: Recurso Visual (20 puntos)

| Nivel | Puntos | Descripción |
|---|---|---|
| **Excelente** | 18-20 | El recurso visual es claro, bien organizado y ayuda significativamente a entender la presentación. Uso creativo. Información visual precisa. Limpio y cuidado. |
| **Muy bueno** | 14-17 | El recurso es claro y generalmente ayuda a la presentación. Bien organizado. Algún detalle menor a mejorar. |
| **Satisfactorio** | 10-13 | El recurso apoya básicamente la presentación. Organización aceptable. Podría ser más claro o completo. |
| **En proceso** | 5-9 | El recurso es confuso o no ayuda a la presentación. Desorganizado o incompleto. |
| **Necesita mejora** | 0-4 | No presenta recurso visual, o es irrelevante para el tema. |

---

### Categoría 4: Organización y Estructura (15 puntos)

| Nivel | Puntos | Descripción |
|---|---|---|
| **Excelente** | 14-15 | La presentación tiene una estructura clara: introducción atractiva, desarrollo ordenado, conclusión memorable. Las ideas fluyen lógicamente. |
| **Muy bueno** | 11-13 | Estructura clara con introducción, desarrollo y conclusión identificables. Las ideas están mayormente organizadas. |
| **Satisfactorio** | 8-10 | Se distinguen las partes de la presentación. Algunas ideas podrían estar mejor ordenadas. |
| **En proceso** | 4-7 | La estructura es difícil de seguir. Las ideas saltan sin orden lógico. |
| **Necesita mejora** | 0-3 | Sin estructura identificable. La presentación es confusa. |

---

### Categoría 5: Manejo del Tiempo y Preparación (10 puntos)

| Nivel | Puntos | Descripción |
|---|---|---|
| **Excelente** | 9-10 | Cumple el tiempo establecido (5-7 min). Demuestra preparación y manejo del tema. Responde preguntas correctamente. |
| **Muy bueno** | 7-8 | Tiempo muy cercano al establecido (4-8 min). Bien preparado. Responde la mayoría de las preguntas. |
| **Satisfactorio** | 5-6 | Tiempo algo fuera del rango (3-4 min o 8-10 min). Preparación básica. Responde algunas preguntas. |
| **En proceso** | 2-4 | Muy por debajo (menos de 3 min) o por encima (más de 10 min). Escasa preparación. |
| **Necesita mejora** | 0-1 | No completó la presentación o no estaba preparado. |
